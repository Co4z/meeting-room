ทุกครั้งที่จะเปิดเว็บไซต์จำเป็นต้องเปิดตัว Runs เผื่อสามารถใน batabase ในเครื่องคุยกับ python ได้

📦 ขั้นตอนที่ 1: เตรียมของจากเครื่องเก่า (Export)
โฟลเดอร์ที่คุณแคปมามีครบเกือบหมดแล้ว ขาดแค่อย่างเดียวคือ "ข้อมูลในฐานข้อมูลปัจจุบัน" (ไฟล์ schema.sql ที่คุณมีอาจจะมีแค่โครงตาราง แต่ไม่มีข้อมูลที่คุณเพิ่งนั่งพิมพ์จำลองไว้)

ไปที่ http://localhost:8080/phpMyAdmin ในเครื่องเก่า

คลิกเลือกฐานข้อมูล meeting_room_db

ไปที่แท็บ Export (ส่งออก) > กดปุ่ม Go (ลงมือ) 4. คุณจะได้ไฟล์ .sql มา 1 ไฟล์ (ที่มีทั้งโครงตารางและข้อมูลห้อง/อุปกรณ์ทั้งหมด) ให้เอาไฟล์นี้มาใส่ไว้ในโฟลเดอร์โปรเจกต์นี้ด้วยครับ

ก๊อปปี้โฟลเดอร์โปรเจกต์นี้ทั้งโฟลเดอร์ใส่ Flash Drive หรือ Google Drive เพื่อไปเครื่องใหม่ได้เลยครับ

💻 ขั้นตอนที่ 2: ลงโปรแกรมพื้นฐานที่เครื่องใหม่
เครื่องใหม่จำเป็นต้องมี 2 โปรแกรมหลักที่เป็นหัวใจของระบบครับ:

ติดตั้ง AppServ (หรือ XAMPP): * เพื่อให้มี MySQL จำลองในเครื่อง

⚠️ จุดสำคัญมาก: ตอนติดตั้ง AppServ เครื่องใหม่ ระบบจะให้ตั้งรหัสผ่าน MySQL Root (Password) ให้คุณตั้งรหัสผ่านให้ตรงกับที่เขียนไว้ในไฟล์ main.py ของคุณนะครับ (เช่น admin1234) ถ้าตั้งไม่ตรง โค้ด Python จะต่อ Database ไม่ติดครับ

ติดตั้ง Python: * โหลด Python มาติดตั้ง (แนะนำเวอร์ชัน 3.9 - 3.11)

⚠️ จุดสำคัญมาก: ตอนกด Install หน้าแรกสุด ต้องติ๊กถูกที่กล่อง "Add Python to PATH" ด้วยนะครับ ไม่งั้นจะใช้คำสั่ง pip ผ่านหน้าจอ Command Prompt ไม่ได้

🗄️ ขั้นตอนที่ 3: นำเข้าฐานข้อมูลที่เครื่องใหม่
เปิด http://localhost:8080/phpMyAdmin ที่เครื่องใหม่

สร้างฐานข้อมูลใหม่ (New) ตั้งชื่อว่า meeting_room_db เลือก Collation เป็น utf8mb4_general_ci (เพื่อรองรับภาษาไทย)

คลิกเข้าฐานข้อมูลที่เพิ่งสร้าง > ไปที่แท็บ Import (นำเข้า)

เลือกไฟล์ .sql ที่เรา Export มาจากเครื่องเก่าในขั้นตอนที่ 1 แล้วกด Go
(แค่นี้ข้อมูลห้อง อุปกรณ์ และคิวจองทั้งหมดก็จะมาโผล่ที่เครื่องใหม่เป๊ะๆ ครับ)
🚀 ขั้นตอนที่ 4: รันระบบ (โชว์ความเทพของ requirements.txt)
เอาโฟลเดอร์โปรเจกต์ไปวางไว้ในเครื่องใหม่ (ไว้ที่ Desktop หรือไดร์ฟ C: ก็ได้ ไม่จำเป็นต้องอยู่ในโฟลเดอร์ www ของ AppServ แล้วครับ เพราะเราใช้ Python รัน)

เปิด Command Prompt (cmd) แล้ว cd เข้าไปที่โฟลเดอร์โปรเจกต์

พิมพ์คำสั่งนี้เพื่อติดตั้งไลบรารีทั้งหมดในรวดเดียว (นี่แหละครับประโยชน์ของไฟล์ requirements ที่ผมบอกห้ามลบ!):

Bash
pip install -r requirements.txt
รอจนมันโหลดเสร็จ แล้วพิมพ์คำสั่งรันเซิร์ฟเวอร์หลังบ้านครับ:

Bash
uvicorn main:app --host 0.0.0.0 --port 8000
(หมายเหตุ: ต้องใช้พอร์ต 8000 นะครับ เพราะโค้ดใน index.html ของเราชี้ API ไปที่ http://localhost:8000)

เปิดเบราว์เซอร์เข้า http://localhost:8000 ระบบจองห้องประชุมของคุณก็จะขึ้นมาใช้งานได้ 100% พร้อมพรีเซนต์ครับ!
